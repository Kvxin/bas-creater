# 国际化方案 (Internationalization)

## 1. 技术选型 (Why vue-i18n)

项目使用 Vue 生态官方的 **`vue-i18n` v11**，并以 **Composition API 模式**
（`legacy: false`）接入。此前的自研 `useI18n()`（一个扁平的 `messages` 常量 +
手写 `t()`）已被完全替换，原因是：

- 官方库提供插值、复数、回退语言 (fallback)、缺失 key 警告等能力，无需自行实现；
- 支持按语言动态切换、`<i18n-t>` 组件、日期/数字本地化等后续扩展；
- 与本项目的 `<script setup>` + Pinia + Vite 技术栈配套，且有完整的 TypeScript 类型。

## 2. 目录结构 (Layout)

```
src/i18n/
  index.ts              # createI18n 实例、语言探测与持久化、<html lang> 同步
  messages/
    index.ts            # 汇总各命名空间为 messages，并导出 MessageSchema
    common.ts           # 通用词汇（复制/删除/重命名/名称/时长…）
    app.ts              # 应用外壳（导出、语言、主题、面板拖拽 aria）
    danmu.ts            # 弹幕领域词汇（三种弹幕类型、默认文案）
    resources.ts        # 资源库面板
    properties.ts       # 属性面板（含关键帧、音频片段属性）
    timeline.ts         # 时间轴面板与轨道
    preview.ts          # 预览/舞台面板
    audio.ts            # 音频编辑控件
    menus.ts            # 右键菜单配置
    dialogs.ts          # 弹幕详情对话框
```

**一个命名空间 = 一个文件 = 同时包含三种语言**，便于对照与审校（见下）。

## 3. 使用方法 (Usage)

组件（`<script setup>`）——直接使用官方 API：

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'
const { t, locale } = useI18n()
</script>

<template>
  <button :title="t('resources.addText')">{{ t('common.add') }}</button>
</template>
```

非组件代码（stores / utils / config）——通过全局实例：

```ts
import { i18n } from '@/i18n'

const name = i18n.global.t('common.duplicateName', { name: '文本弹幕' })
```

> 注意：`@/i18n` **不再导出** `useI18n`。组件里请从 `vue-i18n` 导入，
> 否则会拿到旧的扁平 key 语义。

语言切换由 `EditorLayout.vue` 的下拉框完成，`locale` 是 vue-i18n 的可写
computed ref，可直接 `v-model`：

```vue
<select v-model="locale">
  <option v-for="item in SUPPORTED_LOCALES" :key="item.value" :value="item.value">
    {{ item.label }}
  </option>
</select>
```

当前语言按 `localStorage['bas-locale']` → 浏览器语言 → `zh-CN` 的顺序探测，
并写回 `localStorage` 与 `<html lang>`（见 `src/i18n/index.ts`）。

## 4. 新增/修改文案 (Adding messages)

每个命名空间文件必须保持同一形状——`en` / `ja` 用 `typeof zhCN` 标注，
**这是三语 key 一致性的编译期保障**（少写或写错 key 会直接编译报错）：

```ts
const zhCN = {
  addText: '添加文本弹幕',
}

const en: typeof zhCN = {
  addText: 'Add text danmaku',
}

const ja: typeof zhCN = {
  addText: 'テキスト弾幕を追加',
}

export default { 'zh-CN': zhCN, en, ja }
```

约定：

- key 使用小驼峰、按语义分组嵌套；跨面板通用的词请放进 `common.ts`，不要复制；
- 插值使用 `{name}`、`{n}` 形式，例如 `keyframeLabel: '关键帧 {n}'`；
- 中文标签允许 `中文 (English Gloss)` 形式（如 `字号 (FontSize)`），
  但 `en` 应去掉冗余注释（`Font size`），`ja` 用本语言术语（`フォントサイズ`）；
- 代码注释、`console.*` 调试输出、CSS 类名、非展示用标识符（如 `'text' | 'button' | 'path'`、
  命令 key `'clip.copy'`）**不翻译**。

新增命名空间时：新建 `src/i18n/messages/<name>.ts`，然后在
`src/i18n/messages/index.ts` 的三处语言对象中各加一行。

新增语言时：在 `src/i18n/index.ts` 的 `SUPPORTED_LOCALES` 与 `Locale` 类型中登记，
并在每个命名空间文件里补一个同形状的语言对象。

## 5. 新增语言的注意事项 (Reactivity & data)

1. **模块级常量必须改为 `computed`**：`const tabs = [{ label: '全部' }]` 只在初始化时求值一次，
   切换语言不会更新。请写成 `computed(() => [...])`，或在模板/函数体内调用 `t()`。
2. **数据类文案是"创建时快照"**：新建弹幕的默认内容（`danmu.defaultText`）、
   默认轨道名（`timeline.defaultTrackName`）、资源副本名（`common.duplicateName`）
   在创建时解析并写入数据，之后切换语言不会改写已有数据 —— 这是刻意行为。
3. **`BAS` 默认值语义**：生成器只在属性"不同于 BAS 默认值"时才输出该属性
   （`isDanmuFieldBasDefault`）。因此文本类默认值改动必须谨慎，
   详见 `src/utils/danmuDefaults.ts` 中的说明。
